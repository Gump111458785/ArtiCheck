# 工作台界面设计记录

2026-10-28 使用 [Taste Skill](https://github.com/Leonxlnx/taste-skill) 改版，保留原生 HTML / CSS / JavaScript、现有 HTTP API 与核查流程。

## 设计决定

选择 `Framed sheet`，seed `1335413223`，没有重抽方向。长时间审查需要稳定的导航与清晰的数据关系：绿色灰阶外框承载导航，白色工作区承载主张与证据；IBM Plex Sans 用于拉丁文字和数字，中文使用系统中文字体。字体随源码分发，授权见 `web/dist/fonts/OFL.txt`。

产品的核心画面是同一条主张的报告值、实验观测值、偏差和容差。实际不一致的数值使用深红色，正常信息保持中性色。摘要从当前运行计算，复核数量从该报告对应的反馈计算；六角色以状态栏呈现，可打开真实输入输出规范。

| 视图 | 优先回答的问题 |
|---|---|
| 核查任务 | 哪些实验主张与证据不一致，需要我复核？ |
| 证据审查 | 这条结论由哪些执行输出支持？ |
| 运行轨迹 | 规划与工具调用按什么顺序产生了结论？ |
| API 契约 | 这项操作对应什么请求、返回值与事件？ |
| 训练交接 | 哪些人工修正已归档，哪些是困难样本候选？ |

手机端折叠导航与角色流程，先显示待关注和待复核数量。主张列表与详情分开呈现，返回时恢复列表滚动位置；复杂事件表保留在自己的横向滚动容器内。

| 视口宽度 | 原版工作台高度 | 改版工作台高度 |

| 1440px | 1542px | 1155px |

检查保留两项有明确理由的例外：`no-data-hue` 的启发式把角色状态栏和执行事件列表当成数量图表，本界面没有数量趋势图，差异由数值和问题状态表达；空反馈页的 `panel-void` 来自填满视口的白色工作区，保留真实空状态。API 页在 390px 有一项字号提示，12px 用于接口元信息和代码注释，接口路径、正文保持 13px 以上。

- 主张与数值对照构成主要内容，装饰性英文标签、四张独立 KPI 卡和彩色角色图标已移除。

- 未新增图表或图例；证据仍关联原始指纹、执行命令和 JSON。
- 手机端验证了菜单、主张详情、返回列表和流程展开。
