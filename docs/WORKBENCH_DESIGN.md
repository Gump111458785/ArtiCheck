# 工作台界面与证据呈现

## 主要视图

| 视图 | 展示的内容 |
|---|---|
| 论文与代码 | PDF、GitHub 提交或 ZIP，以及本次复现范围 |
| 实验主张 | 论文原文、页码和可检验的主张 |
| 运行条件 | 实验计划、材料核验、资源要求和实际执行配置 |
| 执行中心 | 任务来源、进度、角色事件和原始阶段输出 |
| 评估结果 | 报告值、实验观测值、偏差、容差及逐项复核 |

桌面视图将证据与上下文并排展示。窄屏折叠全局导航，主张列表与详情分开呈现，长表和原始输出可在各自容器内滚动。

## 状态与结果

- 问题数、指标和待复核数对应同一次运行。人工意见与机器报告分别保存。
- 缺失结果、未知值和实测零值有各自的显示状态。未执行的项目显示当前可用的材料和证据。
- 资源视图区分目标机器快照、可用容量和执行器限额。硬件数据来自采集或上传的快照。
- 材料回执、冻结计划、实际运行和报告通过版本指纹关联。公开案例在独立归档中保留来源、协议偏差和覆盖范围。
