# 集中反馈改版与验收计划

本轮采用已安装的 Anthropic frontend-design 指南；沿用现有原生模块栈与真实材料、报告、运行记录。全部反馈合并实施，历史已验收能力做回归。

## 视觉方案

主题为“实验审查案卷”：先读结论，再查指标和依据；过程是一条可展开的实验时间线。使用冷白纸面、深蓝墨色与蓝色操作强调，状态使用独立语义色。

- 纸面 `#ffffff`，框架 `#f3f6fa`，主文字 `#172b3d`，次文字 `#526779`，操作强调 `#1f5f94`，未通过 `#a6293b`；通过使用 `#17664b`。
- 字体保留 IBM Plex Sans 与系统中文字体；标题 24–28px、区块标题 16–18px、正文 14–15px、元信息 12–13px。
- 登录采用独立页面，主表单仅用户名、密码、眼睛按钮、登录；无注册和网站访问码。
- 开始页保留新建入口与真实公开案例，案例采用深蓝卡片，验收状态有独立标记；教学入口移到帮助。
- 结果页使用一页式报告：醒目结论 → 覆盖范围与问题 → 指标比较 → 图表与证据。执行计划、日志、角色事件合并到过程详情页。
- 审查中隐藏完整上传表单，左侧工作进度与材料摘要持续可见；真实活动默认展开、按阶段分组。

```text
独立登录页 → 开始 / 最近项目 → 命名项目 → 导入并初步识别材料
                                     → 需求选择弹窗（四种模式及说明）
                                     → 自动审查与计划执行
                                     → 一页式结果报告
                                          └─ 过程详情（计划 / 日志 / 角色事件）
```

审阅：避免沿用泛用四卡仪表盘和装饰性渐变。视觉重点集中在公开案例与最终结论；原始材料、技术参数和过程不抢占主要阅读位置。通过、未通过与未验收分别依据实际记录，不能以任务完成冒充论文通过。
